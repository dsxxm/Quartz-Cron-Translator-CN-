# Quartz-Cron-Translator-CN-
将quartz的cron(通常在xxljob中更常见)翻译成中文自然语言

# 注意事项
此代码不会校验输入的Cron的合法性,因此请自行保证Cron的合法性,必须为标准的Quartz Cron
